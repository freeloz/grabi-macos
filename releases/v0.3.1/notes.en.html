Grabi 0.3.1

  • Grabi is now signed and notarized by Apple. No more "app is damaged" warning — it opens on a double-click, no workarounds.
  • Shared links open the app. A Grabi Cloud link no longer sends you to the browser if you have Grabi installed.
  • Sign in with Apple, alongside Google, if you choose to use Grabi Cloud.
  • Important if you were on the beta: this release changes the app’s internal identity, so the auto-updater can’t make the jump. Download it once from grabi.net and drag the new one into Applications. macOS will ask for screen and microphone permission again; it’s the last time.
